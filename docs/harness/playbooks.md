# Playbooks

## Add or update an asset

1. Open or reference one GitHub issue describing the repeated need and evidence.
2. Create a focused branch.
3. Use the relevant template under `docs/templates/`.
4. Run the local repository checks.
5. Open a pull request and complete its security checklist.
6. Address CI and owner review; merge only when both pass.

## Add a skill from another source

1. Review the source license and provenance.
2. Copy only the skill directory; do not import repository history or caches.
3. Review every script and referenced file.
4. Document attribution and pin external dependencies.
5. Run local checks and let CI scan the complete skill directory.
